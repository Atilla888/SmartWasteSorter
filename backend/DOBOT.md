## Dobot Magician SDK Setup (Required for Robot Control)

Robot control requires the official Dobot Magician SDK.

### Requirements
- Windows
- 64-bit Python
- Dobot Magician connected via USB

### Installation Steps
1. Download the Dobot Magician SDK from the official Dobot website
2. Copy all files into:
   backend/dobot_magician/
3. Verify setup by running the application:
   frontend: /my-sortingwaste-project -> npm run dev
   backend: /backend -> python main.py
